## 📂 Featured Projects & Scripts

| Project / Script | Description | Key Concepts Demonstrated |
| :--- | :--- | :--- |
| **`basic_calculator.py`** | A CLI calculator performing basic arithmetic operations based on user input. | Type casting, input handling, conditional logic (`if/elif/else`) |⭐
| **`banking_program.py`** | A simple interactive banking system to deposit, withdraw, and check account balances. | Functions (`def`), variable state management, input validation |⭐
| **`countdown_program.py`** | A functional countdown timer script that outputs formatted time in real time. | `time` module (`time.sleep`), `while`/`for` loops, string formatting |⭐

| **`rock_paper_scissors.py`** | A playable Rock-Paper-Scissors game against a randomized computer opponent. | `random.choice()`, game loops, conditional win/loss evaluation |⭐
